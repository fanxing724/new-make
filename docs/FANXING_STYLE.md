# 番星 · 星轨手记

这套风格延续番星个人主页已有的银蓝角色、四角星与星轨。固定的识别元素连接不同项目，各项目保留自己的用途、文案、配色和图形。

## 固定识别

- 角色：银蓝长发、青色眼睛、星形发饰，使用现有日光与星空两幅插画。
- 标记：沿用个人主页的四角星轮廓，搭配细线星轨，不给每个项目重新造一个作者标志。
- 署名：`番星 / 星轨手记`。
- 主张：`代码交给 AI，想法留给自己。`
- 字体：系统无衬线；小标签可以使用等宽字体。中文标题与正文保留足够留白。
- 布局：左侧是项目名称与用途，右侧是角色。项目主题图形作为角色旁的小徽记，避开面部。

## 配色

| 用途 | 色值 |
| --- | --- |
| 星空底色 | `#0c1425` |
| 星光蓝 | `#9bc9ff` |
| 日光底色 | `#f2f6fc` |
| 日光文字 | `#23334d` |
| 陪伴粉 | `#d993ad` |
| 网络橙 | `#db925c` |
| 心跳绿 | `#65bfa6` |

深浅两版使用各自的原有插画和底色。正文用高对比文字，项目主题色用于点缀和徽记。

## 每个项目自己的表达

- 陪伴核心：手记与心形，讲 AI 的日常、记忆与陪伴。
- 网络透镜：网络路由，讲出口、分流和检测线索。
- Pulse：心跳曲线，讲轻量值守与状态记录。
- 编译器：终端窗口，讲写下代码、输入与运行结果。
- 设备探索：保留修复手记的语气，记录实际观察和实验结果。

项目文案先说明用途，再补项目来由。保留“还在探索”的真实状态，不给尚未验证的能力写确定的效果承诺。

## README 节奏

1. 封面：名称、一句定位、固定署名。
2. 实际演示：真实界面截图或操作动图，注明版本或日期。
3. 三个主要特色：用具体的使用场景说明。
4. 开始使用：下载、安装或部署入口。
5. 继续了解：详细文档、项目来源、致谢与许可。

封面里保留简短标题，完整介绍保留为 Markdown 文字。统计卡适合主页汇总，项目 README 优先展示项目本身。

## 在 new-make 中维护

`projects.config.json` 的 `owners.fanxing724.portrait` 启用角色风格。单个项目可设置 `portrait: false` 改用纯矢量封面。其他作者默认使用矢量封面，不自动套用番星角色。

标题、标语、故事、分类、主题色和图形仍按项目配置。生成后的 `fanxing724/projects/style.html` 是明暗可切换的风格样板，`projects/index.html` 展示全部项目。

插画直接复用 `assets/art/`，经过 `cards/art.ts` 内联进 SVG。只进行等比缩放和裁切；文字与图形在 SVG 中合成，不修改原始角色素材。
