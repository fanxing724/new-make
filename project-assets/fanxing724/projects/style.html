03 / README RHYTHM

让读者先看见项目，再走进细节。

① 专属封面角色、名字和一句定位
② 实际演示真实界面截图或操作动图
③ 三个特色说明最值得尝试的事情
④ 开始使用下载、安装或部署入口
⑤ 继续了解详细文档、来源与许可

封面用于识别，真实界面用于展示用途。截图注明版本或日期；使用说明、项目来源与许可保留为可检索的文字。
